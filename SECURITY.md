# Security and privacy reports

Pocket Financer processes sensitive financial alerts entirely on the user's device. Please do not place a real message, account identifier, phone number, transaction screenshot, signing credential, or model transcript in an issue.

Do not open a regular issue for a vulnerability. Contact the repository owner through an agreed private channel first, then use synthetic evidence to describe a reproduction. Include the affected app version, iOS version, device model, and whether the issue involves Shortcuts ingestion, persistence, model parsing, or local erasure.

GitHub private vulnerability reporting is not available for this private repository. This policy deliberately does not link to a security-advisory form that would fail or expose a reporter to a dead end.

The maintainers will confirm receipt, reproduce privately, assess whether stored evidence or transaction integrity is affected, and coordinate a fix before public disclosure.
